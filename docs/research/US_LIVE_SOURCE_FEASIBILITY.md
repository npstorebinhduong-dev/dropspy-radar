# US live ads source feasibility — v0.2

Assessed 2026-11-03 (UTC). This report separates code capability, live network availability, data licensing and market coverage. **No live US ad dataset was retrieved or verified during this task.** Import readiness is verified using synthetic records in isolated tests; it does not establish live source readiness.

## Current evidence

- Runtime network policy is restricted; the applied custom allowlist remains empty. Previously saved drafts are not applied runtime policy.
- Normal HTTPS reads of the [Meta API reference](https://developers.facebook.com/docs/graph-api/reference/ads_archive/), [TikTok Commercial Content API getting started](https://developers.tiktok.com/doc/commercial-content-api-getting-started), and [TikTok Creative Center Top Ads](https://ads.tiktok.com/business/creativecenter/inspiration/topads/pc/en) each failed at the environment proxy: `Tunnel connection failed: 403 Forbidden`. These are environment blockers, **not responses proving that the platforms prohibit or support a query**.
- Presence-only checks: META_ACCESS_TOKEN, TIKTOK_CLIENT_KEY, TIKTOK_CLIENT_SECRET, APIFY_TOKEN and LOOOT_TOKEN are absent. No values or credential files were read. No paid request, login, browser challenge solving or internal endpoint invocation was performed.
- Phase 2 exact-commit evidence remains in [REPOSITORY_AUDIT.md](REPOSITORY_AUDIT.md). Source code demonstrates request/field handling, not current platform entitlement, current prices or service reliability.

Status definitions: **VERIFIED** = the stated capability was exercised with evidence and the stated scope; **UNVERIFIED** = insufficient live/contract evidence; **BLOCKED** = a concrete prerequisite or network operation currently prevents evaluation. A source can be BLOCKED for runtime while its geographic or commercial entitlement is UNVERIFIED.

## Production source gate implemented in v0.2

[Registry and capability checks](../../apps/api/app/sources.py) require `approval_status=approved`, `live_enabled=true`, operational `state=ready`, supported country and filters before a live request. `MODE=live` or `ENABLE_META_PUBLIC_COLLECTION=1` alone cannot bypass registry approval. Source approval must correspond to actual permission; changing a database field does not create platform rights or credentials.

The six requested source types are registered. A seventh disabled `legacy-unknown` entry preserves older real-mode records without inventing provenance. File import is separate from live collection; its permission is per dataset. Source state metadata is a declaration, not proof that a service responds successfully.

Current active production collectors: **none**. The public Meta experimental path remains blocked by the gate and unavailable network; official Meta/TikTok clients and licensed providers have not been integrated into production.
